# 世界立繪規格（地圖 Sprite）

- 版本: v2.6（2026-08-13；正式採單方向完整 strip 與原生尺寸場景驗收）
- 狀態: 現行正式規格
- 適用: overworld 主角、NPC、事件人型與會直接出現在地圖上的魔物
- 流程: [世界立繪流程.md](../pipeline/世界立繪流程.md)
- Prompt: [role_world.md](../pipeline/prompt/role_world.md)、[enemies_world.md](../pipeline/prompt/enemies_world.md)

---

## 一、製作與 runtime 單位

- **Authoring unit**：單一方向、單一動作家族的一條 horizontal strip。
- **Runtime unit**：切成每幀一張透明 PNG；同一 strip 共用 cell、global scale、腳底線與 bottom-center anchor。
- 不把逐幀獨立產圖當正式流程，也不直接要求模型一次生成四方向 `9×4` sheet；方向分開製作與驗收，最後才組成 runtime 動畫。
- 同一角色的所有 strip 必須以核可的 `Down Idle` world seed 為造型、比例、色盤與 Pixel Art 密度真相源。

## 二、動畫與方向

### 正式 walk

- 每方向 9 幀：`0=Idle`，`1..8=walk cycle`。
- 方向固定 `Up / Left / Down / Right`，對應 `world_scene.gd` 的 `Idle<Dir>`／`Walk<Dir>`。
- `1..8` 為獨立循環，`8→1` 必須無縫；Idle 不插進走路循環。

| 幀 | 步態相位 |
|---|---|
| 1 | 左腳接觸：左腳踏出、右腳在後 |
| 2 | 左腳承重：左腳穩定、右腳開始離地 |
| 3 | 左腳 passing：右腳向前通過、雙腳距離收近 |
| 4 | 左腳 recovery：左腳向後收、準備切換右腳 |
| 5 | 右腳接觸：右腳踏出、左腳在後 |
| 6 | 右腳承重：右腳穩定、左腳開始離地 |
| 7 | 右腳 passing：左腳向前通過、雙腳距離收近 |
| 8 | 右腳 recovery：右腳向後收，可接回 frame 1 |

### 三幀簡易版／事件版

- 簡易人型：`Idle / Step L / Step R`；runtime `1..8` 依 `L/R` 交替。
- 事件 actor／魔物：依劇情製作三幀 idle、呼吸或踏步 strip，命名可用 `Field`、`Upright` 等語意姿態。
- `Step L`／`Step R` 必須交換鞋尖落點、膝蓋重疊、褲管明暗、髖部遮擋與承重腳；不得以整體平移、鏡像或衣角擺動冒充換腳。

## 三、尺寸與構圖

- 標準人型 cell：`64×64px`，runtime scale `1.0`。
- 大型角色依場景需要，以 `32px` 為增量擴充橫向或縱向；例如四足大型熊 `96×64px`、正面直立熊 `64×96px`。
- 所有幀腳底落在同一基準線；bottom-center 為唯一 root anchor。
- 角色、武器、帽沿、尾巴等完整留在 cell 內，不得被格界裁切。
- 不逐幀 fit-to-cell；整條 strip 只允許一個 global scale，避免人物呼吸時忽大忽小。

## 四、視覺風格

- 高品質 Pixel Art、約二頭身世界比例；先讀得出方向、人物身份、衣著輪廓與腳步，再追求小細節。
- 目標地圖截圖是色調與細節密度基準：中低飽和、中對比、頂光、柔和體積陰影；避免純黑粗描邊、過亮紅橘與戰鬥圖式高反差金屬高光。
- 描邊以深棕／深灰棕為主；縮小後不得比地表紋理或附近 NPC 更銳利、更花。
- 主角、NPC、事件魔物放入同一地圖時，像素尺寸、頭部視覺量、輪廓粗細與明暗階數必須屬於同一視覺家族。
- overworld 不使用戰鬥舉武器姿勢；任務指定持物例外。
- 圖內不得包含地面、投影、文字、UI、格線或浮水印。

## 五、接地影子

- 影子由角色節點下方獨立生成，**不得烘進 sprite PNG**。
- 顏色固定 RGB `(58,52,44)`。
- 中心 Alpha `127/255`（約 50.1%）。
- 邊緣最低 Alpha `13/255`（約 5%）。
- 依橢圓距離使用 `(1-distance)^1.35` 漸淡，橢圓外才完全透明。
- `64px` cell 基準中心 `x=31`（相對 cell 中心左移 1px）、垂直範圍 `y=57..63`；寬度約為可見身形 `0.95×`，人型限制在 `24..36px`。
- 大型角色依體積調整，例如直立熊可用 `84×14px`；仍須在實景合成中確認不偏右、不窄成腳邊污點，也不黑成實心橢圓。

## 六、逐幀一致性

- 服裝、髮型、五官、配件、物種特徵、色盤與 outline 不跨幀變形或缺層。
- 腳底 root-lock；身體可因步態上下起伏，但不得整張角色漂移。
- 側向朝向按鼻尖／腳尖判讀，不能只信 prompt slot；`Left` 朝畫面左，`Right` 朝畫面右。
- 正面 `Down`：角色左腳位於畫面右；`Step L` 是畫面右腳向前。背面同理依角色解剖判讀。
- 四足角色要保持軀幹長度、肩胛、臀部與四肢數量一致；直立角色要保持腳底與身體中軸穩定。

## 七、交付規格

- Raw：滿版單一鍵色背景、單列等格 strip。
- Alpha：透明 RGBA strip＋透明逐幀 PNG；可見鍵色殘點 `0`，透明區 RGB residue `0`。
- Review：raw strip、逐幀 montage、原生尺寸目標場景合成；多幀需要時另附 GIF。
- Runtime：標準角色 `assets/char/<id>_<Dir>_0..8.png`；事件 actor 可用 `<id>_Field_0..2.png`／`<id>_Upright_0..2.png`。
- 像素素材 import 使用 Nearest。

## 八、驗收標準

- 必須同時檢查放大靜態圖與原生尺寸地圖合成；只看大圖精緻度不算通過。
- 同框至少放一名核可角色比對比例、色盤、像素密度與影子。
- 動畫 strip 必須一次生成完整動作，且通過 raw 靜態、alpha 靜態、場景與動態四層驗收。
- 任一格造型漂移、腳點滑動、去背殘色、縮小不可讀或與地圖畫風分離，就退回前一 Gate 修正。
