# 世界立繪規格（地圖移動素材；高品質像素・二頭身）

- 版本: v2.5（2026-08-13；補入羅瑟爾／漢克／瑪莎 Down 三幀簡易版）
- 狀態: 草稿（芳蕾鎮六名 NPC 已整合原生 64px Down 素材；正式 8 相位與其餘方向仍待完成）
- 適用: overworld **地圖上移動**的素材（走路／待機）。戰鬥素材見 [戰鬥立繪規格.md](戰鬥立繪規格.md)；對話立繪見 [角色立繪規格.md](角色立繪規格.md)；產圖 prompt 見 [`docs/pipeline/prompt/role_world.md`](../pipeline/prompt/role_world.md)、[`enemies_world.md`](../pipeline/prompt/enemies_world.md)

敵人一般不在地圖走動（遭遇即進戰鬥），本檔以我方角色為主；日後若有地圖走動的敵人再比照 `enemies_world`。

---

## 一、動畫與方向

- **walk**：9 幀（第 0＝中性站立，第 1–8＝步態）× **4 方向**。
- overworld **待機**＝ walk 第 0 幀（中性站立）。
- 列序固定 `row0=Up(背面) / row1=Left / row2=Down(正面) / row3=Right`（LPC 標準、對齊 `world_scene.gd`，不可換序）。

## 二、排版與解析度

- 一張 sheet：**列＝方向、欄＝幀**，規則網格、cell 一致、角色畫在格內。
- 產圖工作尺寸可用 **256×256**；路德／亞倫終版基準 runtime cell 固定 **64×64**，原生 scale `1.0`、bottom-center offset `-32px`。其他角色的 96px 過渡素材仍以 `2/3` 顯示，待逐角遷移。
- 走路 sheet：9 欄 × 4 列。

## 三、風格

- **目標**：與角色立繪外觀一致的二頭身世界 sprite；但**世界地圖的色盤、光影與邊緣質感優先於戰鬥立繪的高對比表現**。縮放仍用 Nearest。
- **地圖相容基準**：以實際放置的目標地圖截圖為 style reference；採中低飽和、中對比、頂光與柔陰影，對齊 [地圖畫面規格 §四](地圖畫面規格.md#四、色彩規則)。避免純黑粗描邊、過亮純紅／純橘與戰鬥用的高反差金屬高光；描邊優先用角色或地圖色盤中的深棕／深灰棕。
- **比例與細節**：角色在地圖上要先讀得出方向、衣著輪廓與腳步；臉部、飾品與裝備細節不得比附近 NPC 或地表紋理更搶眼。無劍版。
- **無劍版**：overworld 走路不舉劍（戰鬥才有劍）。
- **接地影子**：使用角色節點下方的獨立半透明深棕橢圓，不得烘進 sprite。64px cell 的基準中心為 `x=31`（相對 cell 中心左移 1px）、垂直範圍 `y=57..63`；寬度依可見身形約 `0.95×` 計算並限制在 `24..36px`，避免影子偏右或窄成腳邊污點。
- 現況為 LPC 像素過渡，見 [`docs/pipeline/世界立繪流程.md`](../pipeline/世界立繪流程.md)「現況與遷移」。

## 四、步態（逐幀一致性）

服裝零缺層、腳底基準線一致、root-lock（身體中心 x／腳底錨點逐幀對齊）、只動該動的部位——同 [戰鬥立繪規格.md §四](戰鬥立繪規格.md)。

**walk 第 0 幀＝中性站立**（雙腳併攏，可當戰鬥 idle 站姿基準）。**第 1–8 幀為獨立循環，`frame 8→1` 無縫**，每方向都要看出左右腳完整交替（側面看前後腳交換、正背面看左右腳交換）：

| 幀 | 步態相位 |
|---|---|
| 1 | 左腳接觸：左腳踏出、右腳在後 |
| 2 | 左腳承重：左腳穩定、右腳開始離地 |
| 3 | 左腳 passing：右腳向前通過、雙腳距離收近 |
| 4 | 左腳 recovery：左腳向後收、準備切換右腳 |
| 5 | 右腳接觸：右腳踏出、左腳在後 |
| 6 | 右腳承重：右腳穩定、左腳開始離地 |
| 7 | 右腳 passing：左腳向前通過、雙腳距離收近 |
| 8 | 右腳 recovery：右腳向後收；可無縫接回 frame 1 |

### 簡易驗證版（Idle＋兩張步態）

簡易版只可用於比例、手感與地圖相容性驗證；每方向固定交付下列三張，不得以鏡像、裁切差異或手部擺動冒充換腳：

| 圖 | 腳位要求 |
|---|---|
| Idle | 中性站立，雙腳不做單腳前踏 |
| Step L | 角色解剖上的左腳為前／接觸腳、右腳在後；正面／背面以左腳相對另一腳更靠前或承重辨識 |
| Step R | 角色解剖上的右腳為前／接觸腳、左腳在後；正面／背面以右腳相對另一腳更靠前或承重辨識 |

`Up / Down / Left / Right` 四個方向都必須各自符合 `Step L → Step R` 的交換；不得因正背面遮擋而兩張都讀成同一隻腳在前。
