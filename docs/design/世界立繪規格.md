# 世界立繪規格（地圖 Sprite）

- 版本: v3.4（2026-08-14；D2 改採 320px logical grid、4× 交付與分層 outline 規則）
- 狀態: 現行正式規格
- 適用: overworld 主角、NPC、事件人型與會直接出現在地圖上的魔物
- 流程唯一來源: [世界立繪流程.md](../pipeline/世界立繪流程.md)
- Prompt 組裝: [role_world.md](../pipeline/prompt/role_world.md)、[enemies_world.md](../pipeline/prompt/enemies_world.md)

> **權威邊界**：本檔是 world sprite 的尺寸、命名、視覺與驗收數值唯一來源；流程文件只定義 Gate 與操作順序，prompt／skill／TASK 只能引用，不得再內嵌另一套數值。角色立繪與戰鬥立繪可依設定身高正規化；world sprite 不依 cm 縮放。

## 一、三層素材與真相源

| 層級 | 正式名稱 | 規格 | 用途／權威性 |
|---|---|---|---|
| D1 | High-res World Design Reference | `1280×1280px`、精緻二頭身、非 Pixel Art、透明 RGBA | 五官、髮型、服裝、配件、材質、色票、方向與不對稱設計的細節真相源；不是 runtime 尺寸真相源 |
| D2 | High-res Pixel Art Reference | `320×320` logical grid、Nearest `4×` 交付 `1280×1280px`、中等細節 Pixel Art、透明 RGBA | D1 的獨立 Pixel Art 轉譯；鎖定輪廓、色階、描邊、像素群與細節取捨，不是高解析像素插畫、runtime 或 strip frame 0 |
| D3 | Approved Native Seed | `64×64px`、原生正式 Pixel Art | 依 D1 身份與 D2 Pixel Art 語言重新詮釋的 world seed；是該方向 strip 的 production 真相源，frame 0 必須逐像素完全一致 |

### D1：High-res World Design Reference

- 固定 `1280×1280px`（`64×20`），採精細、非 Pixel Art 的日系 JRPG 角色素材。
- D1 必須是未來 D2 共用輪廓的**精緻二頭身設計稿**：含頭髮的頭部約佔完整角色高度 `48..50%`，下巴以下的軀幹、手臂、短腿與鞋靴合計約一個頭高。禁止產成三至五頭身角色立繪後再縮小，也禁止把二頭身誤解成低細節或 Pixel Art。
- 一般人型共用同一套 world Q 版頭身、站姿尺度與鏡頭角度；不按角色設定的 158／165／178 cm 拉高矮。
- 高解析的用途是看清細節，不是縮小來源。D1 禁止經 resize、quantization、色彩取樣或銳化直接成為 D2／D3。
- `Down` 是主外觀 reference；下列情況必須另補 `Side`／`Up` 方向 reference 或同等清楚的設計標註：背包、披風背面、側馬尾、單肩裝備、武器掛側、傷痕、胸針、腰包等正面看不到或左右不對稱的特徵。
- 每名角色建立「64px 身份特徵表」：必留、可簡化、必捨棄、禁止新增。不得企圖把 D1 所有細紋塞入 64px。

正式命名：

```text
world_design_ref_down_1280_{raw,alpha}.png
world_design_ref_side_1280_{raw,alpha}.png   # 需要時
world_design_ref_up_1280_{raw,alpha}.png     # 需要時
```

### D2：Pixel Art Reference

- D2 必須在固定 `320×320` logical grid 上完成；每個 logical pixel 對應同色同 Alpha 的 `4×4` physical pixels，再以 Nearest `4×` 交付精確 `1280×1280px`。所有輪廓、色塊、描邊、高光與 Alpha 邊界都必須對齊同一個 grid origin，不得出現小於 `4×4px` 的細節。
- D2 使用與 D1 相同的精緻二頭身比例、姿勢、輪廓量體與方向；logical grid 是 D2 自身的作畫結構，不得把 D1 resize、quantize 或自動取色後冒充 D2。
- D2 是 D1 的**中等細節高解析 Pixel Art 版本**：必須保留角色身份、主要服裝層、主配色與不對稱特徵，並主動把微小刺繡、單根髮絲、皮膚微陰影與材質雜訊簡化成較大的代表性像素群。
- D2 的細節密度必須落在兩個邊界之間：比低解析／舊 world sprite 樣張多一級髮束、五官、衣褶、飾邊與材質資訊；同時明顯少於高解析像素插畫，不得逐髮絲、逐刺繡或以大量微小色塊重現 D1。
- D2 應一眼可見較大的 hard-edged pixel clusters 與清楚的省略決策。臉部保留眼、眉、口與主要陰影；頭髮保留大髮束及少量高光帶；服裝保留主分層、代表性接縫、主飾品與少量重點紋樣，不完整複製所有裝飾。
- D2 雖有自己的 `320×320` logical grid，仍是視覺參考稿，不受 D3 的 bbox、腳底線或 native validator 約束，也禁止直接縮小 `5×` 成為 `64×64` D3。
- 產圖工具的候選若不是精確 grid，可先落到 `320×320` 再 Nearest `4×` 正規化；W2 只驗正規化後的成品。此步只允許正規化已獨立產生的 D2 候選，不得拿來把 D1 自動轉成 D2。
- 舊 `*_native64_ref.png`／`make_native64_ref.py` 產物僅為歷史 layout diagnostic，不得當 D2、D3 或 strip source。

正式命名：

```text
world_pixel_ref_down_1280_{raw,alpha}.png
world_pixel_ref_side_1280_{raw,alpha}.png   # 需要時
world_pixel_ref_up_1280_{raw,alpha}.png     # 需要時
```

### D3：Approved Native Seed

- D3 必須在 `64×64` 原生 grid 上重新設計；以 D1 作為身份與細節真相源、D2 作為 Pixel Art 語言真相源，並參考已核可 world 角色與目標地圖取捨細節。
- 禁止把 D1 或 D2 resize、quantize、collapse、銳化或縮小補像素後當 D3；D3 是刻意的 native-scale reinterpretation，不要求與 D2 逐像素對應。
- 舊 runtime world sprite 可作為風格、輪廓密度與地圖融合比較，但必須依現行高度、寬度、anchor 與 Gate 重新核可，不得自動升格為 D3。
- `Down` D3 先凍結為角色的主 world seed；`Left／Right／Up` 依 D1／D2 方向資料與 Down D3 製作，各方向也要有自己的 D3，作為該方向 walk strip frame 0。
- D3 一旦核可即版本凍結。若 D1 外觀改版，所有下游 D2、D3、strip 都必須標示待重驗，不可默認仍相容。

正式命名：`seed_<dir>_native_64.png`。

## 二、D3／strip 標準人型尺寸與體型

- 本節尺寸只適用 D3、strip 與 runtime frame，不套用於 D1／D2。
- Cell：固定 `64×64px`；runtime scale 固定 `1.0`。
- 一般人型完整可見 bbox：高度 `58..64px`、寬度 `28..40px`。
- 建議常態高度 `60..62px`；使用完整 `64px` 高時，頭頂會到 `y=0`、腳底到 `y=63`，必須額外證明所有動畫幀都不裁切。
- 尺寸量測包含頭髮、馬尾、兜帽、披風與衣服外輪廓；不包含透明留白、場景影子，也不以獨立長武器／法杖尖端決定一般人型 bbox。
- 最低接地 opaque pixel 固定在 `y=63`；水平 root 為 cell bottom-center，概念座標 `(32,64)`，雙腳視覺中心須穩定落在 cell 中央。
- world sprite 不呈現一般人型之間的實際 cm 差。年齡、體格與角色差異改由肩寬、頭身、輪廓、姿態、服裝量體表現。
- 小孩、矮人、巨漢、非人型與大型魔物是例外體型：W0 先按場景可讀性鎖定 cell 與 bbox，不從設定 cm 自動換算，也不得套用一般人型範圍硬拉伸。
- 大型角色以 `32px` 為 cell 增量，例如四足大型熊 `96×64px`、正面直立熊 `64×96px`。

### 武器、持物與換裝

- 一般 world idle 預設不採戰鬥舉武器姿勢；長武器、法杖預設收起或不顯示。
- 任務要求持物時，W0 必須明訂持物是否計入 cell；超出 64px 時用較大 cell 或獨立圖層，不得把整個角色縮小遷就武器。
- 裝備更換預設不改 world sprite；使用 canonical travel outfit。只有重要劇情造型另建完整 variant，狀態光效優先使用 shader／獨立 FX，避免服裝×裝備×狀態組合爆炸。

## 三、方向、鏡像與動畫單位

### 正式名詞

- **Native Seed**：單張 64×64 D3，不稱為 strip。
- **Walk Strip**：單一方向 9 格，標準人型正式 Alpha 尺寸 `576×64px`。
- **Idle Animation Strip**：未來若加入眨眼／呼吸，另作 `N×64px`；不得混入 Walk Strip 的 `1..8`。
- **Runtime frames**：由正式 strip 切成每幀一張透明 PNG。

### 正式 walk

- 方向固定 `Down / Left / Right / Up`，對應 `world_scene.gd` 的 `Idle<Dir>`／`Walk<Dir>`。
- 每方向 9 幀：`0=該方向 Native Seed`，`1..8=walk cycle`；runtime 只循環 `1..8`，Idle 不插入 walk。
- 四個方向分開製作與驗收，不直接生成 `9×4` sheet。
- 同一 strip 必須一次完成，所有格共用 cell、global scale、Pixel Art 密度、腳底線與 bottom-center root；禁止逐幀 fit-to-cell 或逐幀各自生成後拼成正式動畫。

| 幀 | 步態相位 |
|---|---|
| 1 | 左腳接觸：左腳踏出、右腳在後 |
| 2 | 左腳承重：左腳穩定、右腳開始離地 |
| 3 | 左腳 passing：右腳向前通過、雙腳距離收近 |
| 4 | 左腳 recovery：左腳向後收、準備切換右腳 |
| 5 | 右腳接觸：右腳踏出、左腳在後 |
| 6 | 右腳承重：右腳穩定、左腳開始離地 |
| 7 | 右腳 passing：左腳向前通過、雙腳距離收近 |
| 8 | 右腳 recovery：右腳向後收，可無縫接回 frame 1 |

### 鏡像規則

- 每個角色在 metadata 記錄 `mirror_safe`。只要有慣用手、側馬尾、疤痕、單肩披風、胸針、腰包、武器掛側或不對稱護具，即為 `false`。
- `mirror_safe=false` 時，Left／Right 必須各自製作；不得鏡像後把不對稱特徵留在錯側。
- 即使 `mirror_safe=true`，鏡像版仍須獨立通過方向、光向、近／遠腿與實景 Gate。

### 三幀簡易版／事件版

- 簡易人型只供 prototype 或明確核可的低成本 NPC：`Idle / Step L / Step R`；不能冒充正式八相位 walk。
- `Step L／Step R` 必須交換鞋尖落點、膝蓋重疊、褲管明暗、髖部遮擋與承重腳；不得只平移、鏡像或擺衣角。
- 事件 actor／魔物可依劇情使用三幀 idle、呼吸或踏步 strip，命名 `Field`、`Upright` 等語意姿態。

## 四、Pixel Art 視覺語言

- D2 與 D3 共用約二頭身輪廓、主配色、描邊傾向、頂光與材質語言；D2 負責中等細節轉譯，D3 負責原生尺度的第二次取捨。
- D2 同時檢查原生 `320×320` 與 Nearest `4×` 的 `1280×1280`：每個 logical pixel 必須完整映射為一致的 `4×4` RGBA block，hard-edged pixel clusters、logical pixel density 與色階必須一致；不得細密到接近平滑插畫或高解析像素插畫，也不得縮成 D3。
- W2 預覽必須同時放入「低細節樣張／候選 D2／過細樣張」作密度校準：候選須比低細節樣張有更多可讀結構，又比過細樣張有更大像素群、更少色階與更少表面紋樣。
- D3 先保證原生 `1×` 的方向、身份、服裝大色塊與腳步可讀，再追求放大細節。
- 一般人型使用相近的頭部視覺量、手腳最小厚度、像素群密度與明暗層級；不得因 D1 細節較多就讓某一角色特別碎或銳利。
- D2 外輪廓標準厚度為 `1 logical pixel`，即交付圖上的 `4×4px`；D3／strip 外輪廓標準厚度為 `1 native pixel`。轉角或遮擋交會可形成較厚色塊，但不得以平行雙線把整圈描成 `2px` 粗框。
- 外輪廓原則上連續，髮束間隙、雙腿分離等刻意負空間除外。亮髮、白衣與淺色配件也必須維持足夠對比，不能在淺色地圖上消失。
- 描邊採色相相容的深棕、深灰棕或局部色的深色版本；避免純黑粗邊。內部只描重要遮擋、臉部、袖口、鞋底與服裝主分層，不為每一道衣褶或裝飾逐條加框。
- D2 不得出現小於 `1 logical pixel` 的線、半透明抗鋸齒或孤立 outline noise；D3／strip 同理不得出現小於 `1 native pixel` 的假細線。避免戰鬥圖式高反差金屬高光。
- 頂光、中低飽和、中對比、柔和體積陰影；目標地圖截圖與一名已核可 world 角色是色調／密度比較基準。
- D1 身份特徵表依序取捨：輪廓與髮型 ＞ 主服裝色塊／披風 ＞ 臉部辨識 pixel ＞ 代表配件 ＞ 刺繡、鈕扣與材質細紋。
- 不得新增 D1／角色設定沒有的腰包、飾帶、金屬件、髮飾或花紋。
- 圖內不得包含地面、烘入影子、文字、UI、格線、發光、外框或浮水印。

## 五、Alpha、色彩與接地影子

- D2、D3、Alpha strip 與 runtime frames 使用 RGBA；正式 Pixel Art 的角色 Alpha 只能是 `0` 或 `255`。D2 的每個 `4×4` block 必須共用相同 RGBA；半透明只供明確指定的 FX，不用於一般角色抗鋸齒邊。
- 可見鍵色殘點必須為 `0`；完全透明 pixel 的 RGB 必須正規化為 `(0,0,0)`。
- 接地影子由 runtime 獨立生成，禁止烘進 sprite。
- 標準影子 RGB `(58,52,44)`；中心 Alpha `127/255`、邊緣最低 Alpha `13/255`，依 `(1-distance)^1.35` 漸淡。
- `64px` cell 影子垂直範圍 `y=57..63`，寬度依角色可見寬度約 `0.95×`，一般人型限制 `28..40px`；實景確認不偏心、不黑成實心斑。

## 六、Runtime 與取樣

- Runtime：`assets/char/<id>_<Dir>_0..8.png`；標準人型每張 `64×64px`、scale `1.0`。
- 像素素材 import 使用 Nearest、lossless、關閉 mipmaps；不得沿用全域 Linear。
- Sprite root／腳點與碰撞、YSort 分離；替換圖片不得改變角色碰撞與世界座標語意。
- 實機必驗 `1280×720` 設計基準與 `1920×1080` 輸出，包含專案實際 `1.8×` camera zoom、移動中 pixel 寬度、subpixel shimmer、方向切換與 follower 對齊。
- 長期不得保留 per-character runtime scale 特例；舊 96px＋`2/3` 素材只屬遷移期。

## 七、版本與失效管理

每個角色／variant 在來源目錄保存 `world_art_meta.json`，至少包含：

```json
{
  "character_id": "<id>",
  "variant": "travel",
  "design_ref_version": 1,
  "pixel_ref_version": 1,
  "native_seed_version": 1,
  "strip_source_seed_version": 1,
  "mirror_safe": false
}
```

- D1 變更五官、服裝、配件、方向或色票時，D2／D3／strip 標記待重驗。
- D2 只改像素取捨時，D3／strip 標記待重驗。
- D3 改版後，所有引用舊 `native_seed_version` 的 strip 必須重驗 frame 0 與實景；不可只靠資料夾名 `final` 判斷相容。

## 八、驗收標準

### D1

- [ ] 精確 `1280×1280`、非 Pixel Art、透明完整輪廓，無裁切、地面、影子、文字或 UI。
- [ ] 含頭髮的頭部約佔完整角色高度 `48..50%`；是精緻二頭身設計稿，不是三至五頭身角色立繪。
- [ ] 一般人型使用共用 world Q 版頭身與站姿尺度，不依 cm 拉高矮。
- [ ] 正／側／背與不對稱特徵足以支援四方向；身份特徵表已定案。

### D2

- [ ] 原生 `320×320` logical grid，Nearest `4×` 後精確 `1280×1280`；全部 `102400` 個 `4×4` block 內 RGBA 一致，無任何小於 grid 單位的細節。
- [ ] 透明完整輪廓；是獨立 Pixel Art 轉譯，不是 D1 的 resize／quantization／自動取色結果，亦不直接縮成 D3。
- [ ] 與 D1 的精緻二頭身比例、姿勢、輪廓量體、服裝層、配色與不對稱特徵一致。
- [ ] 原尺寸檢查時較大像素群清楚、logical pixel density 一致，無模糊抗鋸齒邊、畫風混用、孤立噪點或假 Pixel Art 紋理。
- [ ] 與低細節及過細樣張並排後，細節密度明確位於兩者之間：多一級角色結構，但沒有逐髮絲、完整刺繡、皮膚微陰影或大量微小 cluster。
- [ ] 外輪廓為連續、足夠對比的 `1 logical pixel` 色選深棕／深灰棕；內部描邊只分隔重要遮擋與服裝主層，無純黑粗框、半透明邊或 outline noise。
- [ ] Alpha 僅 `0/255`；描邊、受控色階、頂光、主要材質與省略規則已足以指導 D3，不使用 D3 bbox、腳底線或 native validator 驗收。

### D3／strip

- [ ] D3 是依 D1／D2 刻意重新詮釋的 `64×64` 原生 Pixel Art，不是任一高解析參考的自動縮圖。
- [ ] 一般人型 bbox 高 `58..64`、寬 `28..40`，最低接地 pixel `y=63`。
- [ ] D3 Alpha 僅 `0/255`；可見鍵色 `0`、透明 RGB residue `0`。
- [ ] 對應 strip frame 0 與 D3 逐像素完全一致。
- [ ] Walk Strip 為 `576×64`；每格皆無裁切、無尺寸漂移、無 root 漂移。
- [ ] `Step L ↔ Step R` 真正交換左右腳；`8→1` 無縫，衣服、五官、不對稱配件與方向不漂移。
- [ ] raw 靜態、Alpha 靜態、逐幀 montage、原生 `1×`、`8×`、實景合成與動態預覽全部通過；GIF 不取代靜態驗收。
