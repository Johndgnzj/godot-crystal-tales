# 戰鬥立繪動畫規格

- 版本: v6.0（2026-08-09；我方戰鬥角色由二頭身改為約 3.5 頭身，新增身高換算、跨角色一致性與分階段驗收標準；敵人比例不變）
- 狀態: 定案（我方 3.5 頭身；路德／瑪琳待重製）
- 適用: 戰鬥時角色與敵人的 idle／hurt／cast／death／attack 動畫、受擊特效

> 角色外觀、服裝、武器與配色：見各單位的 battle art description。Pixel Art、3.5 頭身比例、去背與產圖方法：見 [`docs/pipeline/battle_art/`](../pipeline/battle_art/workflow.md)。

## 零、我方角色比例與身高標準

### 0.1 內部頭身比例

- 我方戰鬥角色統一為**約 3.5 頭身**；從頭髮最高點到下巴為一個頭高，從頭髮最高點到鞋底為全身高度。
- 靜態 Seed 的可接受區間為 **3.3～3.7 頭身**；不得回到頭與身體各約一半的二頭身輪廓。
- 年齡、性別與體格差異用肩寬、四肢粗細、姿態與服裝量體現，**不用切換頭身家族**表現。
- 現行角色基準為亞倫、莉莉、潔絲的已驗收 Battle Seed；路德與瑪琳的舊二頭身素材只是技術參考，不得當作新動作的外觀 reference。
- 世界地圖行走圖可繼續使用二頭身；我方戰鬥立繪與 overworld sprite 是兩套獨立規格。

### 0.2 角色身高與 runtime 顯示

頭身比例先統一，再用角色設定身高決定 runtime 大小。以潔絲 `167 cm = 250px` 為顯示基準，中性站姿的人體可見高度（不含武器、飛揚髮束與外圍留白）按下式換算：

`target_px = 250 × character_height_cm ÷ 167`

| 角色 | 設定身高 | 中性顯示目標 |
|---|---:|---:|
| 瑪琳 | 158 cm | 236.5 px |
| 莉莉 | 162 cm | 242.5 px |
| 路德 | 165 cm | 247.0 px |
| 潔絲 | 167 cm | 250.0 px |
| 亞倫 | 178 cm | 266.5 px |

此數值量的是**人體主體可見高度**，不是圖片畫布高度。同一角色的 attack／hurt／cast 以 idle 的主體高度為基準，整段動畫共用一個倍率；不得逐幀重算而造成縮放呼吸。

## 一、外觀 Seed（所有動畫之前）

每個單位必須先建立並驗收一張獨立的 **seed**。seed 是唯一的角色外觀錨點，只定義臉、髮型、服裝、配色、身形比例與基準面向。持武器角色另有獨立的 weapon reference，鎖定武器外觀。

- seed 為中性備戰站姿，**不屬於 idle、hurt、cast、death、attack 的任何一幀**，不可匯入 runtime。
- 每次產動作首幀或 strip 都必須以核可的 seed 圖作 image reference；換對話時也必須重新附圖。
- seed 的正式來源檔固定為 `battle_seed_raw.png` 與 `battle_seed_alpha.png`，不得附日期。
- 持武器單位的 seed 必須鎖定主手、持握位置與武器總長相對角色身高；獨立 `battle_weapon_<id>_alpha.png` 必須鎖定刀身／劍身、護手、劍柄、柄尾、材質與主配色。每次產 seed、動作首幀或 strip 時，都必須實際附上 weapon reference，不能只提供路徑。
- 武器可依角色手部與動作構圖做整體縮放，使拇指與四指完整環握劍柄、手腕與劍柄同軸；不得拉長劍柄、縮短刀身、改變護手或破壞 weapon reference 的部件比例。

## 二、動畫集合與幀數

| 動畫 | 幀數 | 動畫用途 |
|---|---:|---|
| **idle** | 4 | 呼吸循環 |
| **hurt** | 1 | 受擊後仰或受擊定格 |
| **cast** | 1 | 詠唱起手定格；法系普攻可併入 `attack` |
| **death** | 1 | 倒下、潰散或死亡定格 |
| **attack** | 依單位特性，基準約 5 | 劍砍、杖詠放、匕首突刺、爪擊等完整攻擊動作 |

規則：

- `idle` 正式交付為 4 幀。允許重用已重繪且驗收的相位幀組成四幀循環（例如潔絲 `0 → 2 → 3 → 2`），但不得用同一張圖機械平移製造假呼吸。
- `hurt`、`cast`、`death` 各自獨立為單幀，不與 `idle` 共用幀。
- `attack` 的幀數依武器與單位特性調整，但必須涵蓋完整起手、命中與收招。
- 同一單位的各動畫必須維持相同外觀、裝備與武器。

## 三、首幀規格

每個動畫先建立並驗收一張首幀，再以首幀作為後續 strip 的造型錨點。首幀不是 `idle` 的替代品，而是各動畫自己的動作定格：

| 動畫 | 首幀必須呈現 |
|---|---|
| **idle** | 與 seed 不同的 idle 呼吸基準姿勢、腳底基準線與角色完整造型 |
| **hurt** | 清楚的受擊反應，例如後仰、護身或失衡；不可改變角色裝備 |
| **cast** | 詠唱起手姿勢、施法手勢與法術媒介；施法手、視線與武器尖端（若使用）皆朝敵方（我方角色為畫面左側）；不產生任何魔法特效，特效由 Godot 另行製作 |
| **death** | 倒下、跪地、潰散等死亡狀態；輪廓仍須能辨識角色 |
| **attack** | 選定招式的攻擊起手姿勢與武器方向；武器完整留在畫布內，長度、比例、配色與 seed 一致 |

首幀驗收順序：`idle → hurt → cast → death → attack`。任一首幀未通過前，不進入該動作的多幀 strip 製作。

## 四、幀相位與 strip 排版

### Idle

4 幀循環相位：

`0 基準 → 1 胸肩微起 → 2 呼吸頂點 → 3 回落 → 0`

- 呼吸主要是小幅上下起伏，不得讓頭部、上半身或武器明顯左右擺動。
- 每幀必須是真正的局部重繪：胸腔、肩膀、手臂、武器、腰帶、裙擺與下半身互相連動；禁止整張角色純垂直平移。
- 膝蓋、裙擺與重心必須吸收呼吸位移；雙腳保持踩地，鞋底基準線與兩腳接地 x 不得滑動。
- 不得用大塊鞋子或腳踝矩形貼回原圖來鎖腳；腳踝、裙擺與鞋面接縫必須自然。
- 武器角度與握法穩定，武器任何部位都不得被裁掉或去背誤刪。
- 首尾幀要可無縫循環；最終循環順序可依實際驗收選幀，必須記錄在該角色 description。

### Attack

基準 5 幀相位：

`0 起手 → 1 蓄力 → 2 揮出 → 3 命中頂點 → 4 收招`

攻擊弧與武器全程不得被裁切；法杖、劍、匕首等武器的動作須符合該單位設定。
持劍者的握法必須可成立：主手拇指與四指完整環握劍柄、手腕與劍柄同軸、劍柄不可穿過手掌，也不可只由中指或無名指夾持。

### Hurt／Cast／Death

各為 1 幀定格，不加入 idle 或 attack 的中間幀。`cast` 不得包含光球、符文、粒子、光暈或發射物；只保留角色姿勢與施法媒介。`death` 若為倒下姿勢，武器自然掉落於原持手附近並完整留在畫布內。

### Strip 排版

- 一張圖只放一個動畫。
- 使用規則網格，欄位由左至右依動作順序排列，單列呈現。
- 同一 strip 的每格尺寸相同。
- 靜態驗收版背景必須是該角色 description 指定的滿版單一鍵色；不得先去背後才補做靜態 strip。
- 幀與幀之間必須保留清楚、固定寬度的空白間距，禁止角色、武器或特效跨越相鄰格。
- 整張 strip 的上、下、左、右都必須保留安全留邊；角色、武器與特效不得貼住畫布邊緣。
- 每一格的角色、武器與特效輪廓前後各至少保留 `85px` 的單色鍵色安全留白；相鄰兩格之間至少為 `170px`。此數值以產圖原始解析度計算，後續縮放不可替代；若武器或特效較長，須再增加留邊。
- 每格腳底位於同一水平基準線。
- 角色身體中心與腳底錨點固定；武器或手臂可在動作中伸出，但不可造成身體漂移。
- 格尺寸由角色與武器輪廓決定，不固定為 `256×256`；必須先容納完整主體與安全留白，再固定同一動作的等格畫布。

## 五、逐幀一致性

- 服裝、髮型、配色、身形比例與武器不可缺層、變色或變形。
- 只改變動作需要的部位，其餘部位保持穩定。
- 腳底基準線、root-lock 與主要輪廓必須穩定。
- 比例必須符合 3.3～3.7 頭身，且與同隊已驗收基準的頭部大小、四肢長度與 Pixel Art 密度屬於同一視覺家族。
- 不得出現 boiling、閃爍、身體漂移或無意義的整體縮放。
- 我方動畫以面向左為基準；敵方動畫以面向右為基準。若只製作一個基準向，另一方向由水平翻轉取得。
- 敵方 `idle` 的呼吸只能造成有意識的小幅局部變化，不得改變怪物輪廓、朝向、裝備或辨識特徵。

## 五之二、戰鬥畫面的顯示大小

runtime 的顯示高度（`battle_state_machine.gd`）：

| 單位 | 顯示基準 |
|---|---|
| 我方 | 以潔絲 `167 cm = 250px` 為基準，依 §0.2 身高公式逐角色換算主體可見高度 |
| 一般敵人 | `FOE_GEO = 110` × `EnemyDef.battle_scale`（**可見像素的幾何均值**，不是高）|
| 大型敵人（`big = true`）| `BOSS_GEO = 188` × `EnemyDef.battle_scale`（同上）|

`battle_scale` 是**資料端**的顯示倍率（1.0＝基準），設計員可逐隻調，只影響大小、不動任何數值或公式；
劇情 boss 想更有壓迫感就調大。例：狂暴洞熊 `battle_scale = 1.5`。
改的位置見 [`../pipeline/設計員指南.md`](../pipeline/設計員指南.md)（注意要改 `content_db.tres` 內嵌那份）。

**敵人為什麼用「幾何均值」而不是顯示高（`_foe_fit()`，2026-07-30）**：敵人貼圖的畫布比例落差極大
（野狼 112×50、骷髏 41×60），舊做法把畫布塞進固定框 `88×98` ＋ `STRETCH_KEEP_ASPECT`，寬扁的四足獸
會被**寬度**卡住——野狼只畫出 88×39，骷髏卻是 67×98，量級完全不一致；而且 `KEEP_ASPECT` 是**置中**，
狼腳浮在地面線上方 29px、離腳下血條很遠（John 實機回饋）。改成量**可見（非透明）像素**、把
`√(可見寬 × 可見高)` 正規化到 `FOE_GEO`，並把**可見底邊踩在地面線、可見水平中心對齊站位 x**。
`FOE_GEO = 110`＝John 從 76／110／150 三檔實機截圖挑定（2026-07-30）：76 是改動前全體幾何均值的
中位數（一致但整體偏小，骷髏只有我方 250px 的 37%）；**110** 讓骷髏約 53%、野狼 165×74，敵我比例合理；
150 起寬扁的狼會互相重疊，且骷髏原生只有 41×60、放大 3 倍後像素塊變粗——**敵人是被放大、我方立繪是被
縮小**（原生 543×724 → 250），要再往上得等敵人戰鬥圖以更高解析度重產。四足／寬扁的怪自然比人形矮而長，
這是預期結果——單隻要再調就用 `battle_scale`。基準只用 idle 第 0 幀量（逐幀重量會抖動），
量不到像素（缺圖、壓縮貼圖）時退回舊的固定框 `FOE_H` / `BOSS_H`。名字、血條、箭頭與飄字錨點
一律掛在正規化後的可見寬高上。

**我方各狀態的大小／地面線一致化**（`_build_fits()`）：idle 是每位角色的基準，先依 §0.2 調整該角色的顯示高度，其餘每張貼圖再被校正到
「人物一樣大、腳踩同一條線」，切狀態不會忽大忽小或上下跳。同一角色的 idle／attack／hurt／death 是分批
產的，畫布尺寸與人物佔比都不同（例：ludo idle 543×724、attack 628×678、hurt/death 1086×1448），
不校正就會位移。校正規則：

| 狀態 | 倍率 | 貼底 |
|---|---|---|
| `idle` | 1.0（基準）| — |
| `attack` strip | 用 strip 中**主體最高**的一幀對齊 idle 主體高度，**整段共用一個倍率**（逐幀算會變成一呼一吸）× `ATTACK_SCALE`（藝術倍率，現全為 1.0）| 逐幀 |
| `hurt` | 同上（直立姿勢，主體高度可比）| 是 |
| `death` | 1.0（躺姿的主體高度沒有可比性，維持素材原始比例）| 是 |

> 「主體高度」＝排除舉起的細長武器後的人物高度（只認不透明像素橫向覆蓋 ≥10% 畫布寬的橫排）。
> 用整個可見範圍會被舉起的劍拉高，等於把人物縮小。

**站位與圖層**（2026-07-30 John 指定）：最前排單位的腳點＝下方「行動」面板上緣往上 15px
（`ROW_Y0 = PANEL_TOP - FRONT_GAP` = 541），往後每排再上移一個 step（我方 70px／敵方 56px）。
**越靠下＝圖層越前**，由 `_sort_units_by_depth()` 依腳點 y 重排子節點順序實現（刻意不用 `z_index`，
否則單位會蓋到下方面板與血條）。我方**剛好三人時三人共用同一個 x**（`HERO_X_ALIGNED`），
其他人數沿用交錯站位 `HERO_X`。

## 六、受擊特效（單位身上播的打擊特效）

被攻擊的單位身上會疊播一組特效，與立繪分開製作、不畫進立繪。**Godot 引擎本身不附任何美術素材**；
現用素材為 2026-07-28 John 提供、AI 生成的手繪筆觸特效幀表（來源與授權見 `CREDITS_素材授權.md`）。
**特效走手繪風、Linear 取樣**，與像素立繪（Nearest）刻意分流——特效是覆蓋層，平滑筆觸不會破壞立繪的像素感。

| 組別 | 檔名 | 觸發時機 | 視覺 |
|---|---|---:|---|
| `slash` | `fx_slash_0..3.png` | 有刃武器普攻（劍／匕首／爪） | 藍白光弧：火花起手 → 光弧最亮 → 弧＋命中閃芒 → 暗色殘煙 |
| `stab` | `fx_stab_0..3.png` | **瑪琳**的普攻（角色專屬，見下方 `SPRITE_FX`） | 藍白直線刺擊：小火花 → 突刺光條 → 命中爆芒 → 消散殘光 |
| `blunt` | `fx_blunt_0.png` | 杖／鈍器／徒手普攻、**敵方普攻預設** | 白色火花＋碎屑 |
| `burst` | `fx_burst_0.png` | 物理系技能命中（`attr != int`） | 紅橙爆散 |
| `magic` | `fx_magic_0..4.png` | 魔法系技能命中（`attr == int`）、敵方具名技 | 藍色爆散 5 幀：星芒亮起 → 最大 → 環擴散 → 碎晶飛散 → 白霧消散（2026-07-30 由單幀升級）|
| `stab_skill` | `fx_stab_skill_0..4.png` | **瑪琳**的技能命中（角色專屬，見下方 `SPRITE_SKILL_FX`） | 藍白斜向刺擊 5 幀：短光尖 → 拉長帶螺旋 → 命中閃芒 → 收束 → 碎光消散 |
| `heal` | `fx_heal_0..3.png` | 治療技／回復道具 | 綠光十字上升（**仍為 64×64 舊佔位圖，待換**）|

規則（`battle_state_machine.gd`：`FX_FRAMES`／`WTYPE_FX`／`_play_hit_fx()`）：

- **武器對映**：`WTYPE_FX` 只把有刃武器對到 `slash`，其餘（含 `weapon_type` 為空的敵人）一律 `blunt`——
  敵人不預設用斬擊。要讓特定怪物改用斬擊，之後在 enemy `.tres` 加 `fx` 欄位指定，不要改預設值。
- **角色專屬對映**：普攻看 `SPRITE_FX`（**優先於 `WTYPE_FX`**）、技能看 `SPRITE_SKILL_FX`
  （**優先於 attr 判斷**）。目前只有瑪琳有：`marin → stab`（普攻）、`marin → stab_skill`（技能）
  （2026-07-30 John：只有瑪琳用刺擊，不是所有匕首）。綁角色而不是武器類別，是因為這屬於「這個角色
  怎麼打」的演出設定——她換武器不該換掉招式感；反之路德／亞倫拿匕首仍是 `slash`。
  **已知取捨**：角色專屬勝過 attr，所以瑪琳若日後學到魔法系技能，也會播 `stab_skill` 而不是 `magic`；
  真的需要區分時再把 `SPRITE_SKILL_FX` 的值改成「attr → fx」的字典。
  日後若每個角色都要專屬特效，再升級成 `PartyMemberDef` 的資料欄位。
- **方向**：素材原方向＝**我方打敵人**。只有打在我方身上（＝敵方揮來）才 `flip_h`。
- **大小**：斬光是斜掃長條，需大於單位才看得出來＝`clamp(單位高 × 1.8, 120, 230)`；**刺擊更細更長、要能穿過目標才有穿透感＝`clamp(單位高 × 2.6, 180, 320)`；斜向刺擊（技能）＝`clamp(單位高 × 2.2, 170, 290)`**；放射狀（火花／爆／魔光／治療）＝`clamp(單位高 × 1.3, 130, 200)`。
- **播放**：多幀＝每幀 `0.07s`（`FX_DT`）一次性不循環；**單幀＝縮放彈出＋淡出**（0.6 → 1.15 → 1.3 同時淡出，`FX_PUNCH`），所以單張素材也有打擊感。
- **時機**：特效**與攻擊動畫同時開始**（普攻＝角色走到目標前、動畫階段起跳那一刻；技能＝原位施放的第 0 秒），
  不等傷害結算。傷害數字／畫面震動仍跟著結算走（攻擊音效有 lead-in，命中聲在尾端），兩者刻意分開。
- **錨點**：對齊該單位**可見像素框**的中心（不是畫布中心，見 `_visible_anchors()`）。

替換素材時遵守（只換圖不用改程式）：

- 位置 `godot-project/assets/battle/`，**檔名與幀數維持不變**（幀數要改需同步 `FX_FRAMES`）。
- 正方形透明 PNG、`256×256`，一幀一檔不做 strip；特效置中、四邊留白至少 8%，不含背景色／文字／框線。
- 亮部白芯 → 主色 → 外緣淡出；已透明的來源不要再做白色 key（會挖破白芯）。
- 多幀素材若在幀表上彼此重疊，切格用「每排指定格數＋最細頸部下刀」，別用空白投影切。
