# 戰鬥背景規格（戰鬥背景長什麼樣）

- 版本: v1.0（2026-07-30，補完站立地面與腳底承托規則）
- 適用: `godot-project/assets/ui/battlebg_*.png`
- 產圖與整合流程: [`docs/pipeline/戰鬥背景流程.md`](../pipeline/戰鬥背景流程.md)

---

## 一、工程硬規格

| 項目 | 規格 |
|---|---|
| **圖片尺寸** | **1280×720（16:9）** |
| **視角** | JRPG 側視戰鬥構圖，帶輕微景深；不用鳥瞰地圖視角 |
| **地面比例** | 畫面下方至少 **2/3** 是連續、清楚的可站立地面；地平線／後方牆腳最晚在畫面高度的 **1/3（y ≤ 240px）** 開始 |
| **角色腳點** | 站位從前排 y≈541px 到後排 y≈301px；整個區間都必須是同一塊可理解的地面 |
| **用途** | 只畫環境；角色、魔物、戰鬥特效與 UI 由 Godot 另行疊加 |

## 二、腳底承托與空間

- 地面必須從前景連續延伸到中後景，讓前、中、後排角色的腳底都有明確承托。
- 地面要有穩定的透視線索、質感與可接觸感，但站位區不可有深溝、斷崖、水面、濃霧、大片全黑或過強的鏡面反光。
- 不可用巨大前景岩石、水晶、草叢、軌道或其他物件切斷左右兩隊之間的站立地面。
- 地面細節以中低對比為主；邊緣可用道具與地貌建立場景辨識度，中間主戰區保持可讀。
- 畫面內不預畫角色投影；但光源與地面明暗必須讓 runtime 角色之後能自然接地。

## 三、構圖與畫面風格

- 畫面上方 1/3 用於天空、洞窟頂、遠景、樹冠或建築高度；不可向下擠壓主戰區。
- 左右邊緣可有大型環境元素作畫框，但不能遮住我方（右側）或敵方（左側）的站位。
- 維持《水晶傳說》手繪 JRPG 背景方向：清楚線稿、細緻材質、中低飽和、環境色光；不做像素化、寫實攝影或 3D render。
- 同地區的戰鬥背景要延續世界地圖的主色、材質與地貌語彙，但不直接複製鳥瞰地圖構圖。

## 四、畫面禁項

- ❌ 文字、字母、數字、logo、浮水印、UI、外框
- ❌ 角色、NPC、魔物、屍體、已畫在地面上的角色投影
- ❌ 只有下方約 1/2 或更少的地面、過低的地平線
- ❌ 戰鬥站位看來像想像的舞台、懸浮平台、視覺無法判斷高度的霧面
- ❌ 在左右站位區放大型遮擋物、強烈光芒或高對比雜訊
