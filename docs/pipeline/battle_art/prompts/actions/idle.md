# idle 動作資料集

## 選項

| ID | 姿勢 | prompt 動作文字 |
|---|---|---|
| `ready_guard` | 標準備戰 | 雙腳前後站立、低重心，主武器保持防守角度，胸肩僅作極小呼吸起伏。 |
| `calm_ready` | 沉穩備戰 | 重心穩定置中，視線鎖定敵方，武器收在可立即出招的位置，呼吸幅度極小。 |

## 硬限制

- idle 是 seed 之後獨立產生的動畫首幀，不可重用 seed。
- 腳底 root-lock，兩隻鞋的接地 x 與鞋底基準線不得滑動；禁止以大塊鞋子／腳踝矩形貼回原圖鎖腳。
- 呼吸主要為小幅上下起伏，胸腔、肩膀、手臂、武器、腰帶、裙擺、膝蓋與重心必須有連動的局部重繪；不得用整張圖垂直平移代替。
- 頭部、上半身與武器不得明顯左右擺動。武器角度與握法穩定，但可隨肩臂有微小、合理的上下連動。
- 首尾幀必須無縫循環，不得改變手勢、朝向、武器外觀或身體比例。
