- 語言: 繁體中文；目標為與手繪世界地圖相容的二頭身、無劍版、9 幀 × 4 方向

## 通則（目標二頭身世界 walk）

產圖前必附兩種 reference：角色外觀 reference，及實際使用的世界地圖截圖。先只產 `Down Idle` 並合成回地圖驗收，通過後才使用同一個世界 style seed 產 walk。不得把戰鬥高對比／純黑粗描邊版本直接挪用。

```
二頭身世界地圖角色 sprite，手繪像素相容的 JRPG 風格。以附上的世界地圖截圖為唯一色調、光影與邊緣質感 reference：中低飽和、中對比、柔和頂光與深棕／深灰棕輪廓；避免純黑粗描邊、刺眼純紅純橘與戰鬥立繪式強烈高光。約 2 頭身高，{{角色外觀／照立繪、無劍版}}；細節以遠距可讀的輪廓與衣著為主，不讓臉部或飾品壓過地圖細節。走路 sprite sheet，4 列＝方向（第0列上/背、第1列左、第2列下/正、第3列右），9 欄＝幀：第0欄中性站立、第1–8欄完整走路循環（左右腳交替，第8→1 無縫）。雙腳同一地面線、每列身體中心對齊。背景：單一平塗螢光{{底色}}滿版到邊，沿輪廓連續深色描邊以利去背。無文字、無 UI、無邊框。
```

## 簡易驗證版補充（Idle＋兩步態）

把上方的 9 欄要求替換成每方向 3 欄，並附上下列不可省略的句子；先交付四方向 `Step L / Step R` 並排檢查圖，再切成 runtime 幀：

```
每方向 3 欄：Idle、Step L、Step R。Step L 必須是角色解剖上的左腳前／接觸、右腳後；Step R 必須是角色解剖上的右腳前／接觸、左腳後。上、下、左、右四個方向都要讓兩張的前腳清楚交換；正面與背面不得因遮擋變成同一隻腳在前。不可用手臂、披風、鏡像或裁切差異假裝換腳。
```
