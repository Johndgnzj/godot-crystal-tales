# World Object Prompt 固定開頭 v1

高品質日系 JRPG 地圖互動物件，top-down 3/4 視角，清楚簡潔的手繪物件輪廓，材質與色彩貼合指定地區的手繪地圖風格。單一物件，置中，透明背景，無地板、草、牆、場景投影、角色、怪物、文字、UI、Logo、發光、粒子或漂浮特效。

畫布尺寸與 bottom-center 錨點固定；物件完整留在畫布內。若物件帶有門口、洞口或可進入落點，入口必須直接接觸物件底邊，但不要求水平置中；bottom-center 僅代表渲染排序 anchor，不代表入口位置。若為建築或可進入結構，正面必須平行於畫布底邊，禁止側向 45° 構圖、斜跨地格或入口朝向側邊；俯視感僅由屋頂與高度表現。優先維持小尺寸縮放後的清楚輪廓與大色塊，避免碎小細節、柔焦與寫實材質。
