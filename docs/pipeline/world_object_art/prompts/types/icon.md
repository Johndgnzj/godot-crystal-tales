# icon 類型模板（背包／選單圖示）

規格（尺寸、路徑、構圖、不可畫進圖裡的東西）在 [`../../../../design/道具武器設計.md` §三](../../../../design/道具武器設計.md)，本檔只提供 prompt 用的選項與狀態文字，不重複規格數字。

## 必填選項

- art id：對應 `.tres` 檔名（`hi_potion`、`iron_sword`）；**同族共用一張時填族名**（`sword_iron`）。
- 類別：`items/*.tres` 的 `cat`（消耗品／材料／劇情）或 `equipment/*.tres` 的 `slot`（武器／防具／腳部／護腕／飾品）。
- 材質與配色：階級差異靠這裡表達（銅→鐵→鋼→秘銀…），同族其餘構圖不變。
- 狀態：固定 `icon`（圖示無狀態變化）。

## 狀態文字

| 狀態 | prompt 文字 |
|---|---|
| `icon` | 單一物件置於**洋紅 #ff00ff 單色底**的正方畫布中央（去背用，沿用專案洋紅鍵慣例；交付時已去背為透明），手繪水彩風、筆觸與世界地圖同家族。武器斜放 45°、刃尖朝右上柄尾朝左下；防具與靴正面微俯視；飾品正面平放。光源自左上，物件自身有柔和明暗但**不畫地面投影**。外輪廓清楚可辨，四邊留少量透明邊。沒有文字、數字、邊框、背景色塊、發光、粒子或稀有度裝飾。 |

## 硬限制

- **稀有度、數量、強化等級、「裝備中」標記一律不畫**——由 UI 程式疊層（理由見規格 §3.5）。
- 底色只能是純洋紅 #ff00ff，**不畫任何場景背景**（含地面、桌面、陰影落點）；圖示是浮在 UI 上，不是擺在場景裡。
- ⚠️ `gen-art` 的 `icon` mode 目前 prompt 寫的是 `dark background`（`gen_image.py:54`），與此處的洋紅鍵不一致；產圖時改用 `--type raw` 自帶洋紅底描述，或先把該 mode 的 prompt 改成洋紅底。
- 不沿用像素風：本類型刻意與 `assets/battle/` 的像素立繪分流。
- 數值、售價、取得條件、任務 flag 不進 prompt。

## 與地圖拾取物的關係（雙交付）

art id 若同時有地圖實體（`descriptions/` 已有描述檔、且 `items/*.tres` 也存在，目前為 `wolf_fang`、`miner_helmet`），**同一次產圖出兩種交付**，不要拆成兩份描述檔：

| 交付 | 尺寸／構圖 | 用途 |
|---|---|---|
| 地圖拾取物 | 32×32、bottom-center 貼地（`quest_item.md`）| 地圖上可撿取的 sprite |
| 背包圖示 | 64×64、正方置中（本檔）| 選單／商店 |

其餘道具與**全部 119 件裝備只有背包圖示這一種**（裝備不會掉在地圖上），來源目錄走 `assets-source/icon/<id>/`。
