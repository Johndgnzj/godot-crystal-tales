# 地圖產圖流程（畫一張手繪地圖 png）

- 版本: v1.1（2026-07-25，驗證地格藍圖的全幅版圖鎖定 prompt；藍圖決定結構，AI 只決定美術）
- 對應 skill: `gen-map-prompt`（問答收需求 → 依本檔模板組 prompt；規則以本檔＋design 規格為準，skill 不內嵌規則）
- 上下游: 連通關係（出入口通哪）以 `assets-source/map/map-def.json` 為權威、用網頁工具維護；產完圖的場景建置／碰撞見 [地圖製作流程.md](地圖製作流程.md)

## 一、流程總覽

```
① 在 map-def.json（網頁工具）定好這張圖的連通與出入口 → 見 地圖製作流程.md §2–3
② 產出藍圖預覽圖（工具⬇️匯出；有高物件會問要不要一併畫進去——產地面圖用「純地形版」，含物件版只當設計總覽，詳見 地圖製作流程.md），並準備同地區已驗收圖作為風格參考（可選）
③ gen-map-prompt 組 prompt；有 40×40 地格藍圖時，先跑 `blueprint_desc.py` 產版圖鎖定段落
④ John 用產圖工具產圖：藍圖圖檔＝結構參考，風格圖＝美術參考
⑤ 預覽驗收（CLAUDE.md 兩階段；要改就留在此步）
⑥ 自查「三、交付檢查清單」→ 存素材源 → 交接圖（場景建置走 地圖製作流程.md）
```

## 二、Prompt 模板（單一真相源）

> 固定開頭是 [`docs/design/地圖畫面規格.md`](../design/地圖畫面規格.md) 各節規則的 prompt 化版本
> ——**改畫面規格時，規格文字與本模板要一起改**（skill 只引用本檔，不另存副本）。
> `{SIZE}` 預設 `1280x1280`。整段同一語言、不混語言。

**有 40×40 地格藍圖時的中文版固定開頭**：

```
附圖一是唯一的結構藍圖：逐格保留所有地形區塊的位置、邊界形狀、道路彎折與出入口接觸畫布邊緣的位置；不可出現附圖的色塊、格線、文字、數字或 UI。附圖二（如有）只作為畫風與材質參考，不可沿用它的道路或地形配置。
俯視 3/4 視角的 RPG 遊戲地圖，手繪像素藝術風格。
畫布正好 {SIZE}，全幅滿版：畫布每個像素都由藍圖指定的地形填滿，沒有圖外深灰、島嶼外框、邊框或留白。道路、障礙與出入口都對齊 32px 網格；主要通道至少 64px 寬。
道路的每一個彎折、寬度變化與連通關係必須逐格跟隨藍圖；不可拉直、平滑、改道、增加、刪除或中斷道路。每個出口都必須直接接觸畫布邊緣，位置與寬度以藍圖為準；不要畫方向箭頭。
山壁、河流、森林等障礙物的輪廓必須逐格跟隨藍圖；地圖內的高地不得被改成外框或邊界。
低飽和、柔和且一致的色調；可行走的地面均勻、低細節且較亮；障礙物（牆／樹／岩石）比地面暗一階。
柔和的頂光，通道上不要有長長的投射陰影。
樹冠不可懸伸覆蓋到可行走的通道上。
不要有文字、字母、數字、格線、UI、浮水印。
不要有角色、NPC、怪物、寶箱、帶字的告示牌（互動物件由遊戲引擎另外擺放）。
```

**附加段**（每張填，續在固定開頭後、同語言）：

- 主題：英 `Theme: {地貌，如 dense pine forest / rocky mine tunnels}`／中 `主題：{地貌}`
- 氛圍色調：英 `Mood/palette: {如 mossy green with grey stone, slightly misty}`／中 `氛圍／色調：{...}`
  ——**同地區的 Mood/palette 描述必須逐字相同**（風格一致性靠這個）
- 佈局與出入口：有藍圖時，直接貼 `blueprint_desc.py` 的完整輸出；它包含版圖鎖定、畫布模式、道路／障礙不可改與精確出入口。無藍圖時才手寫空間骨架與出入口。

> **該圖有 40×40 地格藍圖時**：先執行 `python3 tools/map_editor/blueprint_desc.py <region> <map>`，並將藍圖預覽圖當作第一張參考圖。不得改用人工摘要取代藍圖；模型是否準確以「與藍圖重疊」驗收。藍圖概念與畫法見 [地圖製作流程.md §2.5](地圖製作流程.md)。
- 地標（純裝飾）：英 `Landmarks (decorative only): {...}`／中 `地標（純裝飾）：{...}`
- boss 房追加：`Include a wide open arena clearing (at least 320x320px) at {位置}, with a slightly distinct ground texture.`
- 城鎮追加（有互動建築時）：
  ```
  Buildings ({N}): {每棟功能＋外觀特徵，如 "an inn with a red roof, a smithy with a stone chimney"}.
  Each building: front facade facing DOWN, door centered at the bottom edge of the facade,
  door 32-64px wide, at least 64px of clear ground in front of each door.
  Each building visually distinct by roof color and shape (no text signs).
  ```
- 前景遮擋層（John 明說才加）：`Also note: this map will need a separate foreground layer; keep tall objects' canopies compact and clearly separable from the ground.`

## 三、交付檢查清單（產完接圖前自查）

1. [ ] 尺寸 1280×1280（或同地區統一尺寸，且能被 32 整除）
2. [ ] 有 terrain 藍圖的地圖為全幅滿版，沒有深灰圖外、島嶼外框或留白
3. [ ] 地圖上沒有指引箭頭；每個出入口開口 ≥2 格、直接接觸畫布邊緣，位置跟 map-def.json 的鄰接關係一致
4. [ ] 相鄰圖開口對位
5. [ ] 圖裡沒有寶箱/告示牌/角色
6. [ ] 檔名照慣例：`assets-source/map/<dir>/<file_prefix>_<key>.png`（如 `east_forest/ef_a.png`；命名推導見 [地圖製作流程.md §2](地圖製作流程.md)）
7. [ ] 成圖與藍圖以 50% 透明度重疊後，道路彎折、障礙輪廓與出口位置沒有偏移
8. [ ] map-def.json 已更新（新圖的 cell／出入口；用網頁工具改）

之後接圖（Agent 做）：檢查尺寸→複製進 `godot-project/assets/map/<dir>/`→reimport→跑 `build_scenes.gd` 建場景＋出入口→交回刷碰撞——完整步驟見 [地圖製作流程.md](地圖製作流程.md) §5–7。
