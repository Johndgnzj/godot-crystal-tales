# 戰鬥背景流程（產圖→驗收→整合）

- 版本: v1.0（2026-07-30）
- 畫面規格: [`docs/design/戰鬥背景規格.md`](../design/戰鬥背景規格.md)
- 對應 skill: `gen-art`

---

## 一、流程

1. 確認地區主題，並取同地區已驗收的地圖或戰鬥背景作風格參考。
2. 依下方固定 prompt 產生 16:9 候選圖。
3. 進行預覽驗收；John 明確通過前，不得放進 `godot-project/assets/`。
4. 驗收通過後，原圖存入 `assets-source/battle/`，正式圖正規化為 1280×720 並存入 `godot-project/assets/ui/battlebg_<area>.png`。
5. 更新 `CREDITS_素材授權.md`，reimport 後執行 Godot headless 檢查與戰鬥畫面驗收。

## 二、Prompt 固定核心

> 這段是 [`docs/design/戰鬥背景規格.md`](../design/戰鬥背景規格.md) 的 prompt 化版本。規格變更時要一起修改。

```text
16:9 的手繪 JRPG 側視戰鬥背景，給 2D 角色 sprite 疊加使用，畫布正好 1280×720。
畫面下方至少三分之二必須是一大片連續、清楚、可站立的地面；後方牆腳或地平線最晚在畫面高度三分之一處開始。
地面從畫面底部一直連續延伸到中後景，讓 y=301到541px 的所有前後排角色腳底都有明確承托，絕不能看起來懸空。
地面要有清楚的透視與質感，站位區保持開闊、中低對比；大型環境元素放在畫面邊緣或上方。
不要有懸浮平台、斷崖、深溝、水面、遮住腳底的濃霧，也不要用物件切斷左右兩隊之間的地面。
無角色、NPC、魔物、屍體、角色投影、戰鬥特效、文字、字母、數字、logo、浮水印、UI 或外框。
維持《水晶傳說》手繪 JRPG 畫面：清楚線稿、細緻材質、中低飽和、自然環境色光；不要像素化、寫實攝影或 3D render。
```

**地區附加段**（接在固定核心後）：

- `主題：{區域、地貌與時段}`
- `色調／光源：{與同地區地圖一致的主色、光源、氣氛}`
- `邊緣元素：{能辨識地區、但不進入站位區的岩石／樹木／建築／水晶等}`

## 三、預覽驗收清單

1. [ ] 寬高比為 16:9；正式整合檔為 1280×720。
2. [ ] 地平線／後方牆腳 y ≤ 240px，畫面下方至少 2/3 是可站立地面。
3. [ ] y=301、421、541px 三條主腳點線都落在連續地面上，沒有視覺懸空。
4. [ ] 左側敵方與右側我方站位開闊，中間移動與特效區沒有高對比雜訊。
5. [ ] 沒有角色、魔物、角色投影、UI、文字、logo 或浮水印。
6. [ ] 色調、材質與地貌語彙能對應所屬世界地區。
7. [ ] 放入戰鬥畫面預覽後，最前與最後排角色都自然接地。
