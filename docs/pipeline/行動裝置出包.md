# 行動裝置出包（Android／iOS）

- 版本: v1.0（2026-08-19）
- 對應任務: [`TASKS/21_觸控支援.md`](../../TASKS/21_觸控支援.md) 階段 3
- 狀態: 專案端設定已就緒；**出包本身需要 John 本機的憑證與工具鏈**（見下方「只有你能做的部分」）

《水晶傳說》同一份 Godot 專案就能出 PC 與行動裝置版；觸控介面由 `TouchControls` autoload 依
`DisplayServer.is_touchscreen_available()` 自動決定要不要出現，**不需要為手機版改任何程式或開分支**。

## 一、專案端已就緒的設定

| 設定 | 值 | 為什麼 |
|---|---|---|
| `display/window/handheld/orientation` | `landscape` | 遊戲是 16:9 橫向 |
| `display/window/stretch/mode` | `canvas_items` | 手繪素材以視窗原生解析度算圖（見 `CLAUDE.md` 渲染選型）|
| `display/window/stretch/aspect` | `keep`（2026-08-19 明確寫入）| **不能用 `expand`**：地圖是整張 1280×720 手繪畫面圖、戰鬥／商店面板是絕對座標，`expand` 會露出圖外空白並讓面板相對邊緣位移。`keep` 在 20:9 手機留左右黑邊，畫面與座標系都完整 |
| `rendering/renderer/rendering_method.mobile` | `gl_compatibility` | 行動 GPU 相容性最好，本專案 2D 不需要 Forward+ |
| 安全區 | `TouchControls._safe_rect()` | 瀏海／圓角／小白條：搖桿與取消鈕依安全區內縮（桌機自動退回整個畫面）|

**觸控目標尺寸**：搖桿命中半徑 147px、取消鈕 54px、世界「調查」按鈕高 52px、戰鬥指令格高 44px
（皆為 1280×720 base 座標，`canvas_items` 會等比放大到實機解析度——1080p 全螢幕約 ×1.5）。
換算後最小的一組（戰鬥指令 44px base ≈ 6.7" 手機上 8mm 見方）已達 iOS 44pt 準則量級。
**未達標的是技能／道具列（~20px base）與室內指令列（~24px base）**，加高會擠爆面板版面，
留待實機回饋後決定是否重排（記在 TASKS/21「已知限制」）。

## 二、只有你能做的部分（需要密碼／憑證，AI 不代做）

1. **安裝 export templates**（本機目前沒有：`~/Library/Application Support/Godot/export_templates/` 不存在）
   → Godot 編輯器 `Editor ▸ Manage Export Templates ▸ Download and Install`，約 1GB。
2. **Android release keystore**：`keytool -genkey` 產生、設密碼，路徑與密碼填進 export preset
   （debug 用 Godot 內建 debug keystore 即可）。
3. **iOS 簽章**：Apple Team ID、bundle identifier、憑證與 provisioning profile（在 Xcode 登入帳號取得）。

## 三、Android

前置：JDK 17、Android SDK（Godot `Editor Settings ▸ Export ▸ Android` 指到 SDK 路徑）。

1. `Project ▸ Install Android Build Template`（要出自訂 build／用外掛時才必須，純出包可略）。
2. `Project ▸ Export ▸ Add ▸ Android`，關鍵欄位：
   - Package `Unique Name`：例 `ai.wising.crystaltales`（一經上架不可改）
   - `Screen ▸ Orientation`：`Landscape`
   - `Min SDK` 留空＝用 Godot 4.7 預設（API 24+）
   - `Architectures`：`arm64-v8a`（實機）＋ 需要模擬器時再加 `x86_64`
   - Release 才填 keystore；Debug 直接 `Export Project` 出 apk 就能側載
3. 實機：手機開開發者模式＋USB 偵錯，`adb install -r <apk>`。

## 四、iOS

前置：Xcode（本機已有）、Apple 開發者帳號。

1. `Project ▸ Export ▸ Add ▸ iOS`，填 Bundle Identifier、Team ID、App Store Team ID。
2. `Export Project` 產出的是 **Xcode 專案（不是 ipa）**；在 Xcode 開啟該專案、選實機、`Run`。
3. 模擬器：Godot 4.x 的 iOS export 預設只出 device 架構，要跑模擬器需在 preset 勾選對應選項
   （或直接用實機測——觸控手感本來就要真機才準）。

## 五、實機驗收清單（觸控）

出到手機／平板後照下列順序走一遍，逐項回報給 AI：

- [ ] 標題：兩個選項直接點得動；「繼續冒險」無存檔時點了沒反應
- [ ] 地圖：左下搖桿走八方向；**搖桿在對話／過場中要消失**（否則點不動左下角推進對話）
- [ ] 世界互動：靠近 NPC／寶箱／鏡草時出現「交談／開啟寶箱／調查」按鈕，點得動
- [ ] 選單：右上選單鈕開得起來；分頁、道具列、稱號卡點得動；長清單能用手指滑
- [ ] 商店：商品列與「購買／販售」頁籤點得動；右下「取消」能離開
- [ ] 室內立繪：指令列點得動（**行高偏小是已知項**，覺得難點就回報）
- [ ] 戰鬥：指令 2×2／技能列／道具列點得動；**直接點敵人立繪選目標**；右下「取消」退回上一層
- [ ] 螢幕邊緣：瀏海／圓角有沒有切到搖桿、取消鈕或血條（安全區是否生效）
- [ ] 20:9 之類的長螢幕：左右黑邊是否可接受（不可接受再談別的做法，見上表 `aspect` 說明）

## 六、還沒處理的

- **UI 整體的安全區**：目前只有 `TouchControls` 依安全區內縮；HUD 血條、戰鬥面板、選單仍是
  1280×720 絕對座標貼邊。`aspect=keep` 下手機通常有黑邊、瀏海落在黑邊上不影響，等實機確認再決定要不要處理。
- **音訊**：行動裝置的音訊延遲／中斷（來電、切到背景）未測。
- **存檔路徑**：`user://` 在 Android／iOS 走各自沙盒，PC 存檔不能直接搬過去（跨裝置同步不在範圍）。
