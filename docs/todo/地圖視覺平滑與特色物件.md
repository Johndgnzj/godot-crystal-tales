# 地圖視覺平滑與特色物件

- 狀態：待後續優化
- 建立日期：2026-07-26
- 影響範圍：手繪畫面地圖產圖 prompt、terrain 藍圖驗收

## 目標

在不改變 terrain 藍圖、碰撞、道路寬度或出入口的前提下，提升手繪地圖的自然感與設計感。

## 待做項目

1. 道路與相鄰障礙的邊界保留原本 32×32px 地格語意，但以草叢、落葉、泥土漸層與小石子做地形內的視覺過渡，減弱直角鋸齒感；不得跨越藍圖地形邊界、縮窄通道或封住出口。
2. 對每片至少連續 5×5 格的阻擋地形區，最多挑選兩片作為視覺重點；每片只放一組完全位於阻擋區內的純裝飾特色物件。
3. 特色物件依地貌選擇：森林可用古樹根盤、覆苔倒木、蕨類石叢或隱約遺跡；岩石／山壁可用崩落岩堆、礦脈露頭、苔蘚石柱或裂縫。
4. 特色物件不得伸入可走地面、道路或出口；不得改變地形輪廓；不得使用寶箱、告示牌、採集點、傳送陣、角色、NPC、怪物或其他可互動物件。

## 後續決策

目前先以 prompt 約束產生器的受限隨機設計。若要讓特色物件的位置可重現且可驗收，評估在 terrain 藍圖增加獨立的 `decor anchors` 層，再由產圖 prompt 逐點遵守。

## 驗收條件

- 成圖與藍圖以 50% 透明度重疊後，道路、阻擋輪廓與出入口沒有偏移。
- 地圖最多出現兩組特色物件，且每組完整落在符合條件的大型阻擋區內。
- 所有碰撞與可走範圍維持由 terrain 藍圖決定。
